# Настройка Revit-MCP

Revit-MCP даёт Claude доступ к **открытой** модели Revit через MCP: можно
вживую читать и создавать элементы, что ускоряет отладку раскладки. Это
**локальный** инструмент.

> ⚠️ В облачном контейнере Claude Code это НЕ работает — там нет запущенного
> Revit. Используйте на своей Windows-машине с установленным Revit 2024
> (Claude Code Desktop / CLI / IDE-расширение).

## Как это устроено

Типовая open-source реализация Revit-MCP состоит из двух частей:
1. **Revit add-in / плагин-мост** — загружается в Revit, открывает локальный
   сокет/HTTP-порт и выполняет команды над активной моделью.
2. **MCP-сервер** (Node.js или .NET) — процесс, который Claude Code запускает
   по `.mcp.json`; он общается с мостом внутри Revit и предоставляет инструменты
   (создать элемент, выбрать, прочитать параметры и т.п.).

Существует несколько проектов «revit-mcp» на GitHub. Перед использованием:
- Проверьте **совместимость с Revit 2024**.
- Просмотрите код/разрешения — мост исполняет команды над вашей моделью.
- Работайте на тестовой копии модели.

## Шаги установки (общая схема)

1. Выбрать актуальный open-source Revit-MCP проект, совместимый с Revit 2024.
2. Установить Revit-часть (add-in): собрать и положить `.addin` + сборку в
   `%AppData%\Autodesk\Revit\Addins\2024`, запустить Revit, активировать мост
   (обычно кнопкой на ленте / командой), запомнить порт.
3. Установить MCP-сервер по инструкции проекта (напр. `npm install` или
   готовый бинарь).
4. Прописать сервер в `.mcp.json` (см. шаблон ниже) для **локального** Claude
   Code и перезапустить сессию.
5. Проверить, что инструменты сервера (`mcp__<server>__*`) появились, и что
   простая команда (например, чтение выбранного элемента) отрабатывает.

## Шаблон `.mcp.json`

В корне репозитория лежит `.mcp.json` с пустым `mcpServers`. Пример заполнения
(подставьте реальную команду/порт из выбранного проекта):

```jsonc
{
  "mcpServers": {
    "revit": {
      // Вариант с Node.js MCP-сервером:
      "command": "node",
      "args": ["<путь-к>/revit-mcp/build/index.js"],
      "env": {
        "REVIT_MCP_PORT": "8080"   // порт сокет-моста внутри Revit
      }
    }
  }
}
```

Для stdio-серверов на .NET — `"command": "dotnet"`, `"args": ["<...>.dll"]`.
Точные значения берите из README выбранного Revit-MCP проекта.

## Замечания по безопасности

- Мост даёт внешнему процессу право менять вашу модель — запускайте только
  доверенные сборки и на копии проекта.
- Держите порт на `localhost`, не пробрасывайте наружу.
- Не коммитьте локальные пути/секреты: реальные значения — в локальном
  `.mcp.json` или пользовательских настройках, не в репозитории.
