# Спецификация (ТЗ): плагин НВФ для Revit 2024

## 1. Цель и область применения

Плагин автоматизирует моделирование навесных вентилируемых фасадов (НВФ) в
Autodesk Revit 2024: раскладку подоблицовочной конструкции (ПОК), облицовки,
слоёв пирога и выпуск спецификаций. Пользователи — проектировщики НВФ и
конструкторы фасадов.

На старте система **параметрическая и абстрактная** (system-agnostic):
конкретный тип фасада (керамогранит, металлокассеты, композит) задаётся
конфигом `FacadeSystem`, а алгоритмы раскладки работают с обобщёнными
параметрами.

## 2. Доменная модель (`RevitNvf.Core`, без Revit)

| Сущность       | Назначение | Ключевые поля |
|----------------|------------|---------------|
| `FacadeSystem` | Конфиг системы | шаги кронштейнов/направляющих, зазоры, толщины слоёв, тип облицовки, размеры панели, ширина шва |
| `Substrate`    | Несущая грань | габариты, базовая точка/оси, проёмы, материал |
| `Bracket`      | Кронштейн | позиция, вылет, тип (несущий/опорный, фикс/скольж) |
| `Guide`        | Направляющая | ориентация (верт/гор), линия, шаг между осями |
| `Panel`        | Облицовочный элемент | прямоугольник раскладки, тип крепления |
| `Layer`        | Слой пирога | тип, толщина |
| `Fastener`     | Крепёж | тип (анкер/заклёпка/кляммер), позиция |

Геометрия Core — в **мм/СИ**, собственные типы точек/векторов (без `XYZ`).
Алгоритмы раскладки — чистые функции `вход (Substrate + FacadeSystem) → набор
позиций (Bracket/Guide/Panel)`; **детерминированы и идемпотентны**.

## 3. Функциональные требования

1. **Раскладка ПОК**: расстановка кронштейнов сеткой по параметрическому шагу
   X×Y на выбранной грани; направляющие между кронштейнами с заданным шагом.
2. **Слои пирога**: утеплитель, ветрозащита, воздушный зазор — по толщинам
   из `FacadeSystem`.
3. **Раскладка облицовки**: панели от базовой точки/оси с учётом ширины шва;
   режим старта (от угла/оси/центрирование).
4. **Угловые и доборные элементы**: на углах, у проёмов, парапета, цоколя.
5. **Привязка** к осям и уровням модели.
6. **Спецификации**: ведомости материалов ПОК и облицовки (количество, длины,
   масса) — через категории и shared parameters семейств.

## 4. Нефункциональные требования

- Производительность на больших фасадах (тысячи элементов) — пакетное
  размещение в одной транзакции.
- Идемпотентность: повторная раскладка с теми же параметрами не плодит
  дубликаты и даёт тот же результат.
- Undo/redo — через транзакции Revit (одна логическая операция = один Undo).
- Тестируемость: вся раскладка покрыта юнит-тестами в `RevitNvf.Core.Tests`.

## 5. Архитектура

```
RevitNvf.sln
 src/
   RevitNvf.Core/        netstandard2.0  — домен, алгоритмы раскладки (без Revit)
   RevitNvf.Revit/       net48           — адаптер: IExternalCommand, транзакции,
                                            чтение выбора, размещение семейств
   RevitNvf.UI/          net48 (WPF)     — Ribbon, dockable-панели, viewmodels
 tests/
   RevitNvf.Core.Tests/  net8.0 (xUnit)  — юнит-тесты Core (кросс-платформенно)
 build/RevitNvf.addin                     — манифест add-in
```

- **Граница Revit**: только `RevitNvf.Revit`/`.UI` знают про `Autodesk.Revit.*`.
  Адаптер переводит выбор пользователя в доменные входные данные, вызывает
  Core, материализует результат в модели внутри `Transaction`.
- **Единицы**: Core — мм; перевод в футы — на границе адаптера
  (`UnitUtils.ConvertToInternalUnits`).
- **Транзакции**: все изменения модели — внутри `Transaction`/`TransactionGroup`.
- **Семейства**: параметрические, размещаются кодом; см. навык
  `revit-family-generation`.

## 6. UI

- Вкладка на ленте Revit с командами (раскладка ПОК, облицовка, спецификации).
- WPF dockable-панель ввода параметров `FacadeSystem` (шаги, зазоры, размеры,
  тип облицовки), пресеты систем.

## 7. Нормативные ориентиры

СП 426.1325800.2020, ГОСТ Р 58154-2018, ГОСТ Р 58155-2018, СП 50.13330 —
как источники параметров и ограничений (шаги крепежа, толщины, зазоры), не
как поверочный расчёт.

## 8. Вне области (на старте)

- Инженерный расчёт ветровых нагрузок и несущей способности (только параметры).
- Сложные криволинейные фасады (MVP — плоские грани).
- Автогенерация рабочих чертежей КМД (только данные для спецификаций).
