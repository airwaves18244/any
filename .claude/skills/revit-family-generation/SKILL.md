# Семейства Revit для элементов НВФ

Элементы ПОК и облицовки моделируются параметрическими семействами,
размещаемыми кодом адаптера. Цель — корректная геометрия **и** попадание в
спецификации (ведомости материалов).

## Категории (BuiltInCategory)

Подбирать осмысленную категорию для каждого элемента, напр.:
- Кронштейны / направляющие — `OST_StructConnections`,
  `OST_GenericModel` или специализированные металлоконструкции, в зависимости
  от того, как нужно считать в спецификациях.
- Облицовочные плиты — `OST_GenericModel` или фасадные панели.
> Категория определяет, в каких ведомостях элемент учитывается — фиксировать
> выбор в `docs/SPECIFICATION.md`.

## Параметры

- **Type parameters** — то, что общее для типоразмера (сечение профиля,
  материал, артикул).
- **Instance parameters** — то, что уникально для экземпляра (длина отреза,
  вылет кронштейна, отметка).
- **Shared parameters** — для попадания в спецификации/теги и обмена между
  семействами; хранить файл общих параметров в репозитории (`build/` или
  `families/`), путь — стабильный.
- Полезные служебные параметры: марка/позиция, артикул, масса, материал.

## Размещение кодом

```csharp
if (!symbol.IsActive) symbol.Activate(); // обязательно перед размещением
var inst = doc.Create.NewFamilyInstance(point, symbol,
                                        host, StructuralType.NonStructural);
```
- Загрузка: `doc.LoadFamily(path, out var family)`; затем получить нужный
  `FamilySymbol` из `family.GetFamilySymbolIds()`.
- Все операции — внутри транзакции (см. навык `revit-api-2024`).
- Геометрия — в футах; параметры длины задавать через корректные единицы.

## Конвенции проекта

- Семейства храним в репозитории (напр. `families/`), версионируем.
- Имена: `NVF_<Элемент>_<Тип>` (напр. `NVF_Bracket_Load`, `NVF_Guide_Vertical`).
- Для каждого семейства — фиксированный набор shared parameters, чтобы
  спецификации были стабильны.
- Параметры, управляемые из плагина (длина отреза, вылет, шаг), — instance.

## Спецификации

- Проектировать семейства так, чтобы ведомости материалов собирались
  автоматически по категориям и shared parameters.
- Масса/длина/количество — через параметры, заполняемые при размещении.
